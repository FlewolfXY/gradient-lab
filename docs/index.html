A SMALL TRANSLATION BETWEEN SENSES

不懂乐理，也能从颜色开始。

这里用一套可解释的规则，把画面翻译成音乐。你可以听懂它，也可以改变它。

色彩 → 调性

主色沿着五度圈找到一个调；画面的明暗与冷暖，给旋律一个起始心情。

浓淡 → 和声层次

颜色越浓，和弦加入的音越丰富。切换音色，听同一组颜色的不同质地。

笔触 → 节奏

画面细节多的地方，音符更密。你亲手添上的笔迹，也会加入循环。

好奇里面的规则？映射方式、边界与五分钟乐理＋

这些是为创作设计的映射规则，不是颜色与情绪之间唯一或客观的对应。算法给一个起点，你来决定喜欢什么。

画面音乐设计直觉
全画主色相调的主音色环与五度圈都是圆，相邻色相走到相邻的调
明度与冷暖大调 / 小调为不同画面给出一个初始心情，随时可以手动改
扫描方向时间轴画面可以像卷轴、瀑布，或一圈圈荡开的水面
区域偏离基调的程度和弦功能相近像停留，差异像走远，再逐渐回到起点
饱和度三和弦、七和弦、九和弦色彩浓一点，和声层次也多一点
明度与亮处的位置音区与旋律轮廓明亮的地方，旋律向上走
边缘 / 细节密度节奏密度笔触密的地方音也密，近黑区域给旋律留白
手绘笔迹独立声部位置决定时间，高度决定调内音高，颜色决定乐器

首尾回到主和弦，每四小节形成一个小句子，旋律强拍靠近和弦音。同一幅画、同一组参数与种子，会得到同一段音乐。

一个仍在探索的问题：当两种颜色势均力敌时，平均色相可能落在画面里不存在的颜色上。现在的规则是一种读法，你也可以通过手动调式和不同扫描方向听另一种解释。
