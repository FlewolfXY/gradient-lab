# paint→MIDI · 画布召唤台

把一幅画从左到右扫描成一段音乐。audio-xray 是"声音 → 图层"的解剖台，这个是反方向的"图层 → 声音"。

## 映射规则（画面 → 音乐决策，不是像素 → 音符）

| 画面 | 音乐 |
|---|---|
| 全画主色相（饱和度加权，灰色不投票）走五度圈 | 主音（调） |
| 明度 + 冷暖 | 大调 / 小调 |
| 从左到右 | 时间轴：画 = 乐谱 |
| 每小节竖条偏离全画基调的程度 | 和弦功能：像基调 → 主功能（家），偏离远 → 属功能（想回家） |
| 饱和度 | 和弦张力：三和弦 → 加 7 音 → 加 9 音 |
| 明度 | 音区高低 |
| 竖条里最亮处的高度 | 旋律轮廓（旋律住在画面最亮处） |
| 细节 / 边缘密度 | 节奏密度（近黑区域 = 休止） |

硬规则保底：第 1 小节和最后 1 小节锁在主和弦；每 4 小节结尾拉向属和弦（终止式）；
所有和弦都在调内、旋律强拍吸附和弦音——所以**保证协和，丑也丑得在调上**。

## 用法

```bash
cd paint-to-midi
./.venv/bin/python paint_to_midi.py 你的画.png
```

可选参数：

```bash
--tempo 72        # 速度，默认 80
--bars 16         # 小节数，默认 16（80BPM 下约 48 秒）
--key E           # 强制主音（不服气色相判的调时用）
--mode minor      # 强制大小调
--seed 3          # 换个随机种子 = 同一幅画的另一个版本
```

不带 `--seed` 时种子由图片内容决定：**同一幅画永远召唤出同一首曲子**。

## 产物（在 `out/图片名/`）

- `preview.wav` —— 立刻能听的粗糙合成预览（正弦波素胚，不代表最终音色）
- `melody.mid` / `chords.mid` / `bass.mid` —— 分轨拖进 Logic，各配一个软件乐器
- `combined.mid` —— 三轨合一版
- `annotated.png` —— 你的画 + 小节线 + 和弦标注：画变成了乐谱
- `report.md` —— 逐小节解释"为什么这块颜色变成了这个和弦"，末尾附五分钟乐理

## 定位

这是素胚生成器，不是成品机。正确流程：

1. 召唤 → 听 preview
2. 拖进 Logic → 换成你的音色（Gradient 时间）
3. Piano Roll 里改掉不顺耳的句子（审美归你）
4. 手动点色：那只只出现一次的鸟

如果 venv 不在了：`python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt`
