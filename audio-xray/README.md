# audio-xray · 音乐解剖台

上传一段音频（30 秒到整首都行），得到一个可以点、可以循环、可以慢放、可以写笔记的"声音图层面板"。

给视觉艺术家的对照表：

| 面板 | 相当于绘画里的 |
|---|---|
| 波形 | 素胚的明度分布 |
| CQT 音高频谱 | 带网格的素描纸：每行一个半音，横线是每个八度的 C，旋律和低音走向直接可见 |
| Mel 频谱 | 高频空气与质感层：鸟、气声、镲片都住在上面 |
| 和弦候选 | 色块按根音着色（十二根音 = 十二色相，小和弦更暗）。是猜测，不是真理 |
| Chroma 色带 | 和声的 Gradient Map——十二个音级就是十二个色相 |
| 三层响度带 | 高频层（空气）/ 中频层（主体）/ 低音层（地面）+ 节奏密度，各自一条平滑曲线 |
| 自动分段 + 中文解说 | 构图分区，每段自动解说"相比上一段发生了什么"（比如：不是更响，而是更亮） |
| 自相似矩阵 | 把整首歌摊平看纹样：亮块 = 两个时间片长得像 |

页面上还有：悬停十字线（指哪读哪，CQT 上直接显示音名）、全曲调性候选、"重新分析"按钮（升级分析管线后不用重新上传）。

## 跑法

```bash
cd audio-xray
./.venv/bin/python app.py
```

然后浏览器打开 <http://127.0.0.1:5199>，拖一个音频文件进去。

第一次分析会慢一点（模型热身），之后整首歌大约 5—20 秒。

如果 venv 不存在（比如换了电脑），重建：

```bash
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
```

## 怎么用它拆歌

1. 上传 Cosmo / AURORA 的一首歌。
2. 先看**自相似矩阵**：哪些段落互相是亮块？那就是重复/副歌/循环变体。
3. 点一个自动分段的卡片 → 自动循环这一段 → 开 50% 慢放细听。
4. 对着 **Mel 频谱**验证直觉："这里不是更响，而是高频打开了"——看上方是不是突然亮起来。
5. 在段落卡片里写你自己的语言："潮湿木柜""鸟突然飞近""低音落地"。点保存，笔记存在本地。
6. 喜欢的段落框选后点"导出选区 WAV"，直接拖进 Logic 当学习素材。

## 支持的格式

wav / mp3 / flac / aiff / ogg 直接读；m4a / aac 会自动用 macOS 自带的 `afconvert` 转码。

## 文件结构

```
audio-xray/
├── app.py            # Flask 服务器：上传、分析、笔记、导出选区
├── analyzer.py       # librosa 分析管线
├── make_test_audio.py# 合成测试音频（开发用）
├── templates/        # 页面
├── static/           # 样式和前端逻辑
└── data/<id>/        # 每首歌：原始文件 + audio.wav + analysis.json + notes.json
```

## 诚实声明

- 自动分段和 BPM 是**候选**，不是标准答案。Cosmo 那种非常规节奏很容易骗过 beat tracker。
- Chroma 只显示音级能量，不直接告诉你和弦名（和弦识别在 v2 计划里）。
